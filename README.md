# Постоялый двор — Небуг

Mobile-first лендинг для частного сектора «Постоялый двор» в Небуге. Основной сценарий страницы: даты и гости → вариант размещения → дополнительные условия → готовый запрос владельцу в WhatsApp.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run build
npm test
npm run lint
```

## Структура

- `app/page.tsx` — интерактивный лендинг и маршрут подбора.
- `app/site-data.ts` — единая конфигурация контакта, вариантов, удобств и сезонных цен 2026 года.
- `app/globals.css` — адаптивная визуальная система, состояния клавиатуры и `prefers-reduced-motion`.
- `.github/workflows/deploy-pages.yml` — сборка и публикация на GitHub Pages.

## Данные и ограничения

- Фактическая основа: Небуг, ул. Приморская, 13А; около 200 м до пляжа; кухня, Wi‑Fi, парковка, мангал, беседка и стиральная машина; WhatsApp +7 918 450-52-26.
- Сезонные цены 2026 года перенесены из опубликованной карточки объекта. Для поездки, которая выходит за опубликованные интервалы, стоимость показывается как «уточняется».
- Размещение с домашними животными и трансфер намеренно не предлагаются в интерфейсе в соответствии с ТЗ.
- Страница не является официальной системой онлайн-бронирования. Наличие и окончательную стоимость подтверждает владелец.
- Фотографии объекта не были переданы в материалы проекта, поэтому первый экран использует нейтральный цветовой блок с честной пометкой.
